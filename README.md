# Modular Synth

KiCad designs for DIY Eurorack modular synthesizer modules.

## Acknowledgements

This project is based on the work of [Erica Synths](https://www.ericasynths.lv/) and [Moritz Klein](https://www.youtube.com/@MoritzKlein0), in particular their collaboration on the **mki x es.EDU** DIY series: nine educational kits (sequencer, VCO, wavefolder, noise/S&H, mixer, VCF, envelope generator, dual VCA, and output stereo mixer with headphone amp) that walk through the design of analog synth circuits step by step. The VCO was the first kit released.

Moritz Klein's YouTube series explaining the circuit design is the main reference. All credit for the original circuit designs goes to them.

## Contents

- `vco/`: KiCad project for a sawtooth-core analog VCO (schematic and PCB), with a separate power block schematic.
- `vcf/`: KiCad project for a VCF (schematic and PCB).
- `envelope-generator/`: KiCad project for an envelope generator (schematic only for now, the PCB is not laid out yet).
